# Fruit Sales Analysis Dashboard | Power BI

## Project Overview
An end-to-end Power BI project focused on analyzing fruit sales performance across customers, products, brands, and retail stores.

## Project Workflow
1. Data Connection and Extraction
2. Data Cleaning and Transformation using Power Query
3. Data Validation and Date Validation
4. Data Modeling and Relationship Building
5. DAX Measures and Calculations
6. Interactive Dashboard Development

## Key Features
- Total Sales and Customer KPIs
- Monthly and Yearly Sales Trends
- Customer Sales Analysis
- Top 5 Stores by Sales
- YTD Sales and Running Total
- Interactive Slicers and Bookmarks

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
